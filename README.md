# Aldeanos a 1 Esmeralda (NeoForge 26.1.2)

Todos los aldeanos cobran 1 esmeralda por sus intercambios, sin necesidad de curarlos.
Solo servidor: los clientes no necesitan el mod. Requiere Java 25 para compilar.

## Compilar
    ./gradlew build
El .jar queda en `build/libs/`. Cópialo a la carpeta `mods`.
